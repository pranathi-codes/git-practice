
## Introduction to Git

---

### 1. Why Do We Need Git?

Without version control, developers may lose code, overwrite teammates' changes, and struggle to identify the latest version.

### 2. What Is Version Control?

A system that records changes to files over time, allowing us to review and restore previous versions.

### 3. What Is Git?

Git is a distributed version control system that tracks changes in a project.

**Key benefits:**

- Complete project history
- Collaboration through branches
- Recovery from mistakes
- Tracking who changed what

### 4. History

- Creator: Linus Torvalds
- Year: 2005
- Purpose: Managing Linux kernel development

### 5. Git vs GitHub

| Git | GitHub |
|---|---|
| Version control tool | Online hosting platform |
| Works locally | Hosts repositories online |
| Tracks changes | Supports collaboration and code sharing |

### 6. Popular Hosting Platforms

- GitHub
- GitLab
- Bitbucket
- Azure DevOps

### 7. Key Takeaway

Git tracks changes; GitHub hosts Git repositories online and makes collaboration easier.
